# Product

## Register

product

## Users

SkillMarket serves developers using Claude Code, Codex, MCP tools, local models, prompts, and agent workflow plugins. They arrive while trying to discover a useful resource quickly, compare fit, and copy or follow the exact install commands needed to try it.

## Product Purpose

SkillMarket is a free curated marketplace for AI coding skills, plugins, prompts, local models, MCP servers, and useful repositories. Success means a visitor can browse, filter, open a concise detail page, and leave with a trustworthy install link, command, or Telegram handoff without needing an account.

## Brand Personality

Sharp, practical, developer-native. The interface should feel polished and confident, but never like a generic SaaS landing page or a decorative showcase that slows down the task.

## Anti-references

Avoid generic SaaS hero templates, over-decorated cards, washed-out low-contrast command blocks, decorative motion in admin or task surfaces, and any v2 marketplace patterns such as payments, creator submissions, reviews, favorites, or long-form tutorial pages.

## Design Principles

- Make install paths immediately scannable and copyable.
- Keep the marketplace dense enough for comparison, but clear enough for quick decisions.
- Preserve the approved dark developer palette with accent used for action and state.
- Use familiar product affordances for commands, forms, filters, and admin workflows.
- Prioritize readability and trust over decorative novelty.

## Accessibility & Inclusion

Target accessible contrast, keyboard-visible focus states, readable command wrapping on small screens, and reduced-motion support for nonessential animation.
